HOW TO USE THIS FILE (read once)
1. Open any AI. Attach or paste: PROJECT.md (sections 2, 6, 8, 9, 11) and this guide.
2. Paste the START PROMPT below.
3. Do ONE task at a time: paste that task's PROMPT, put the code in frontend/, run it, check the ACCEPT line.
4. After each task: git commit, then add one line to progress/FARHAN.txt (example: "F4 done - login and setup screens").
5. If the AI quota runs out: open another account/AI, paste the RESUME PROMPT, attach progress/FARHAN.txt. Continue from the next task.

QUOTA-SAVING RULES
- One task (one page or one component group) per chat. Start a NEW chat for each task.
- Paste only the files the task needs (for example src/api/client.ts and the page you are changing).
- End every prompt with: "Output only the changed or new files, no explanations."
- Build with mocks first (VITE_USE_MOCKS=true) so you are never blocked on the backend.
- Reuse components. Do not ask the AI to restyle the whole app. Keep the design tokens file as the only place for colors.
- Free fallbacks if everyone is out of quota: Gemini, ChatGPT free, DeepSeek, Claude free tier.
